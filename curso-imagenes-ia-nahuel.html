Módulo 01

Entender la herramienta

Qué es GPT Image 2 y por qué cambia todo

No es un filtro de Instagram. GPT Image 2 es un modelo que entiende tu foto y puede transformarla — cambiarle el fondo, el ambiente, la iluminación, el estilo — manteniendo el producto real tal como es.

La diferencia clave con otras IAs: podés conversar con él. Si el resultado no te gusta, le decís qué cambiar y lo ajusta. No tenés que empezar de cero cada vez. Es como trabajar con un fotógrafo que entiende lo que pedís.

Cómo accedés: ChatGPT Plus → ícono de adjunto (clip) → seleccionás tu foto → escribís el prompt debajo.

Lo que podés lograr: fotos de catálogo con fondo blanco, imágenes lifestyle con ambiente, flat lays, variaciones de packaging, formatos para Stories — todo partiendo de una foto simple con el celular.

Módulo 02

La foto de partida

Lo más importante del proceso

La IA no hace milagros con una foto mala. Mientras mejor sea la foto original, mejor el resultado final. Pero tampoco necesitás un estudio fotográfico — el celular alcanza.

Qué necesitás en la foto original:

  • Producto enfocado y bien iluminado (luz natural de ventana funciona perfecto)
  • Fondo simple — blanco, gris, madera, tela. Nada con objetos que distraigan
  • Foto horizontal o cuadrada, mínimo 1000px
  • Sin sombras duras encima del producto

Lo que NO importa tanto:

  • No necesita ser perfecta. Fondo desprolijo, un poco oscura — la IA puede compensar
  • No necesita ser de cámara profesional. El celular sirve
  • El ángulo no tiene que ser perfecto
Ejercicio práctico: Tomá una foto del producto en tu mesa con luz de ventana de día. Eso es suficiente para arrancar. Hacé 3 fotos distintas y usá la más nítida.
Módulo 03

Estructura del prompt perfecto

La fórmula que funciona siempre

Un prompt bien armado tiene 4 partes:

[QUÉ HACER con la foto] + [ESTILO visual] + [AMBIENTE / fondo] + [DETALLES técnicos]

Ejemplo real para un producto gourmet:

Prompt modelo
"Usá esta foto del producto como referencia. Mantenelo exactamente igual — mismo envase, misma etiqueta, mismos colores. Colocalo sobre una superficie de mármol blanco con fondo neutro claro. Iluminación de estudio suave, luz lateral que genere profundidad. Estilo fotografía de producto gourmet premium, editorial, limpio. Sin elementos extra, sin personas."

Las palabras clave que más funcionan:

  • mantenelo exactamente igual — para que no invente el producto
  • fotografía de producto editorial — para el estilo
  • iluminación de estudio suave — para que no quede flat
  • fondo neutro / superficie de mármol / madera natural — para el ambiente
  • sin elementos extra — para que no agregue cosas raras

Módulo 05

El flujo de trabajo real

Los 5 pasos que usás siempre

1
Tomás la foto
Producto sobre superficie simple, buena luz natural. 2 minutos. Hacé 3 versiones y usá la más nítida.
2
Abrís ChatGPT y subís la foto
Ícono de clip (adjunto) → seleccionás la foto. Esperás a que cargue antes de escribir.
3
Primer prompt
Usás la estructura del Módulo 3. Pedís la versión base. No seas vago — cuanto más específico, mejor el resultado.
4
Iterás en la conversación
Si algo no quedó bien, le decís exactamente qué: "la iluminación quedó muy dura, suavizala" / "el fondo tiene que ser más oscuro" / "el producto se deformó, mantenelo fiel a la foto original".
5
Descargás y usás
Click derecho sobre la imagen → guardar. Lista para publicar. Mínimo 1080px para redes.
Módulo 06

Errores comunes

Qué falla y cómo corregirlo

El problema
El producto se deforma o cambia — la IA inventa la etiqueta
La solución
Agregá: "mantené el producto exactamente igual a la foto, no modifiques la etiqueta ni los colores del envase"
El problema
El resultado parece artificial o generado por computadora
La solución
Siempre usá "fotografía realista" en el prompt. Evitá pedir estilos muy fantasiosos.
El problema
La imagen queda genérica, sin identidad
La solución
Mencioná una referencia específica: "estilo Caviaroli, producto gourmet premium" o "estilo revista Vogue gastronómica"
El problema
El fondo se ve falso, composición digital obvia
La solución
Pedí: "integración natural del producto con el ambiente, no composición digital"
El problema
Querés lo mismo pero con diferente fondo
La solución
Dentro de la misma conversación: "todo igual que la imagen anterior pero cambiá el fondo a negro mate"

Módulo 09

Procesar todo el catálogo en batch

De manual a automático — API de OpenAI

Hacer las fotos una por una en ChatGPT funciona para 10–15 imágenes. Para procesar todo el catálogo de Caviaroli de una sola vez, usamos la API de OpenAI — un script en Python que toma todas las fotos y las transforma automáticamente.

Costo real: $5–10 USD alcanza para procesar 50–100 fotos con rebrand completo. Una sola vez.

Cómo conseguir la API Key — 5 pasos:

1
Crear cuenta en OpenAI
Entrás a platform.openai.com → "Sign up" con tu email o cuenta de Google.
2
Cargar crédito mínimo
Menú izquierdo → Billing → "Add payment details". Cargás $5 USD con tarjeta Visa/Mastercard (débito funciona).
3
Crear la API Key
Menú izquierdo → API Keys → "Create new secret key". Nombre sugerido: caviaroli-rebrand.
4
Guardar la key
Copiás el código que empieza con sk-... — solo se muestra una vez. Guardalo antes de cerrar la pantalla.
5
Ejecutar el script de rebrand
El script lee todas las fotos scrapeadas, aplica el prompt de rebrand y guarda las imágenes listas para subir a TiendaNube.
Referencia visual objetivo: tienda.havanna.com.ar — fondo blanco limpio, producto centrado, sombra suave. Ese es el resultado para el catálogo de Caviaroli.
Prompt de rebrand — Havanna style
"Tomá este producto y colocalo sobre fondo blanco puro. Sombra difusa suave debajo. Iluminación pareja de estudio, sin sombras duras. Mantené el producto exactamente igual — mismo envase, misma etiqueta, mismos colores. Resultado limpio para catálogo de tienda online, estilo tienda gourmet premium. Sin elementos extra, sin personas, sin texto adicional."
